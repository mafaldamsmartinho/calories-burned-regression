# calories-burned-regression
Regression ML project predicting calories burned from physiological and exercise features. Includes preprocessing, model comparison, cross-validation, and evaluation.

Goal: predict calories burned
Dataset: Kaggle Calories Burnt Prediction
Methods: preprocessing, scaling, one-hot encoding, train/test split, 5-fold CV
Models: Linear Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost/CatBoost
Metrics: MAE, RMSE, R²
Main result: best-performing model and score
